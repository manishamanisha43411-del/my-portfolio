IRCTC Railway Ticket Reservation System

A web-based railway ticket reservation application developed to simplify train searching and passenger booking.

HTML · CSS · Bootstrap · Python · Flask · MySQL

Project Overview

The IRCTC Railway Ticket Reservation System is a web application developed using Python Flask and MySQL. It provides a simple interface for users to register, log in, search for trains and enter passenger details for ticket booking.

Problem Statement

Searching for train information and managing booking details can be difficult without an organized system. This project provides a simple web-based approach to manage the railway reservation process.

Key Features

  • User registration
  • User login
  • Train search functionality
  • Train search results
  • Passenger details entry
  • Booking confirmation interface

Technologies Used

  • Frontend: HTML, CSS, Bootstrap
  • Backend: Python, Flask
  • Database: MySQL

My Role

I developed this project as part of my Python Full Stack development learning. I worked on the application structure, user interface, railway search flow and database integration.
