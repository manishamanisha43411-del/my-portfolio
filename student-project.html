Student Management System

A web-based application developed to manage student information and perform basic student record operations.

HTML CSS Bootstrap Python Django MySQL

Project Overview

The Student Management System is a web application developed using Python Django and MySQL. It helps manage student information in an organized way. Users can perform basic operations such as adding, viewing, updating and deleting student records.

Problem Statement

Managing student details manually can take time and make it difficult to maintain records. This project provides a simple web-based approach to organize student information.

Key Features

  • Add new student details
  • View student records
  • Update existing student information
  • Delete student records
  • Store student information in a MySQL database

Student Information

The application manages the following details:

  • Student Name
  • Email Address
  • Department
  • Address

Technologies Used

  • Frontend: HTML, CSS, Bootstrap
  • Backend: Python, Django
  • Database: MySQL

My Role

I developed this project as part of my Python Full Stack development learning. I worked on the application structure, student record operations and database integration.
